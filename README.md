# 雨课堂 视频连播（yuketang-video-autoplay）

一个很窄的小工具：**只做一件事——把雨课堂课程里「未开始」的视频逐个播完**。
不加速、不刷时长、不答题、不改作业，进度仍然由平台自己的播放器上报，行为和挂着页面看视频一样。

> 用途仅限个人学习时省去「一个个点下一集」的重复劳动。请遵守所在学校与平台的规则，风险自负。

---

## 一、怎么用（不用装 DSH，也不用提前装 Node）

### Windows：双击 `run.bat`

第一次运行会自动做三件事：

1. 找不到 Node 就下载**便携版 Node 20**（约 30 MB，解压到本目录 `.runtime\`，不进系统 PATH）；
2. 安装 `playwright-core`（约 3 MB，只用来连 Chrome 的调试端口，不下载浏览器）；
3. 启动/连接 Chrome，开始连播。

参数直接跟在后面，例如只播 10 个：

```bat
run.bat 10
```

### 前提：Chrome 里已经登录雨课堂

- `run.bat` 会用本目录 `pw-profile\` 作为浏览器 profile 启动 Chrome，并在 `--remote-debugging-port=9333` 上暴露调试端口。
- **第一次**需要在这个 Chrome 窗口里手动登录雨课堂（扫码或账密），登录态会留在 `pw-profile\`；
  之后每次直接双击 `run.bat` 就行，不用再登录。
- 如果你已经有一个开着雨课堂的 Chrome，也可以自己用调试端口启动它（见下），脚本会复用，不会重复开 profile：

```bat
chrome.exe --remote-debugging-port=9333 --user-data-dir="D:\some\profile"
```

> ⚠️ 同一个 profile 同一时刻只能被一个 Chrome 占用。报「profile 被占用」就先关掉别的 Chrome 窗口。

### 需要打开的页面

脚本要能找到**「学习进度」页**（地址里含 `studentLog`，页面里是左侧章节 + 视频列表的 iframe）。
两种方式：

1. 手动在 Chrome 里点进：课程 → 学习进度；
2. 或者在 `config.json` 里把 `courseUrl` 填成该页面的地址，脚本会自动打开它。

找不到这个页面时脚本会直接退出并提示，不会乱点。

### macOS / Linux

```bash
./run.sh          # 需要系统里有 node >= 18
```

## 二、它到底做了什么

```
autoplay.mjs   入口：探活 CDP →（必要时拉起 Chrome）→ 找 studentLog 页 → 交给连播器
watch-runner.mjs  连播器：列出「未开始」的视频 → 逐个打开 → 播完 → 校验完成度 → 下一个
play-one.mjs   只播指定的一集（调试用）：node play-one.mjs 57
```

连播器每轮做的事：

1. 在 `studycontent` iframe 里找 `div.leaf-detail` 中带「未开始 / Video」的行；
2. 拦截 `window.open` 拿到该行真实地址（不新开窗口，避免抢焦点）；
3. 复用**同一个**视频标签页打开地址，伪装 `visibilityState = visible`；
4. 读播放器上的「完成度：x%」，**从已计入的进度往前 15 秒续播**，不重看；
5. 播放期间发现暂停就 `play()`，把倍速强制设回 **1×**（平台对非 1 倍速常常不计进度）；
6. 播完再读完成度，若 `< 92%` 自动从头补播一次；
7. 每 5 个刷新一次目录，更新剩余数量；全部做完写 `.watch-remaining.json` 并退出。

运行日志：控制台 + 本目录 `.watch-log.txt`（每次一行，带时间戳）。

## 三、配置 `config.json`

| 字段 | 默认 | 说明 |
|---|---|---|
| `cdpPort` | `9333` | Chrome 调试端口 |
| `chromePath` | `""` | 留空自动找常见安装路径；也可写绝对路径 |
| `profileDir` | `./pw-profile` | Chrome 用户目录（登录态存这里） |
| `courseUrl` | `""` | 「学习进度」页地址；填了就在没有标签页时自动打开 |
| `limit` | `999` | 一次最多播多少个（也可命令行参数覆盖） |

## 四、注意事项（踩过的坑）

1. **必须 1 倍速**。播放器把倍速改回 1 是故意的：非 1 倍速时完成度经常不涨。
2. **不要同时开两个实例**。两个进程抢同一个标签页，进度会互相打架。
3. **登录过期会停**。跳回 `/web/?next=` 时脚本判定会话失效并停止本批，重新登录后再跑即可。
4. **验证码会停**。检测到 `captcha` 帧立刻停下，需要人工过。
5. **断点续播靠完成度**。中途关掉不影响：下次从已计入的进度继续，不会重看整集。
6. **只处理视频**，讨论/作业/考试一律不碰。
7. 脚本不保存任何账号密码，登录态只存在本地 `pw-profile\`（已被 `.gitignore` 忽略）。
